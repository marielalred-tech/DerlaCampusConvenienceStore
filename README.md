# Campus Corner Store POS

A simple point-of-sale system for a campus convenience store. Built with plain HTML, CSS and JavaScript (no database, no server).

## Features
- Product list with prices, category tabs and search
- Add / remove items, adjust quantities (+ / − or type a number)
- Live total and item count
- Cash payment with quick-cash buttons, change calculation and validation
- Digital receipt (printable) and a New transaction button

## Run
Open `index.html` in a browser (or use the VS Code "Live Server" extension).
